# Pinchora Türkçe terim sözlüğü

Oyuncuya görünen metinlerde aşağıdaki karşılıkları tutarlı kullanın. Discord komutları ve teknik anahtarlar (`/critterdrop`, `owner:` gibi) çevrilmez.

| English | Türkçe | Kullanım |
| --- | --- | --- |
| shell(s) | kabuk | Para birimi; sayıdan sonra değişmez: `2.500 kabuk`. |
| pearl(s) | inci | İkinci para birimi ve Sıcak İnci oyunundaki nesne. |
| critter(s) | yaratık | Toplanan küçük kıyı yaratıkları. `critter drop` için **yaratık etkinliği**. Genel deniz canlıları için `deniz canlısı` kullanılabilir. |
| plaza | meydan | Sunucunun ortak alanı. |
| stall | tezgâh | Oyuncular arası satış yeri; genel mağaza için kullanılmaz. |
| shop / store | mağaza / puan mağazası | `/shop` için **mağaza**, sunucu puanıyla rol alınan `/store` için **puan mağazası**. |
| house | ev | Oyuncunun odaları olan evi. |
| pet | hayvan | Kategori adlarında bağlam için **evcil hayvan**; kartlarda `HAYVAN`. |
| badge | rozet | Profil ve koleksiyon rozeti. |
| fish book | balık defteri | Yakalanan türlerin kaydı. |
| Tidepool Dex | Gelgit Havuzu Defteri | Yaratık ve buluntu koleksiyonu. |
| fragment | parçacık | Tekrarların dönüştüğü takas birimi. |
| Moonpearl Isles | Ay İncisi Adaları | Evcil hayvan gezisi. |
| Starfall Sandbar | Yıldız Yağmuru Kumluğu | Evcil hayvan gezisi. |

Kullanıcı adı, eşya adı ve özel ad gibi yer tutuculara Türkçe ek yapıştırmayın; `**{name}** adlı yaratık` gibi yapıları tercih edin. Türkçe sayılarda binlik ayırıcı `.` ve ondalık ayırıcı `,` kullanılır; İngilizce biçim korunur.
